# BLOON McDONALD THUMB 🍔👍

A tiny absurd browser arcade game where a single Thumb tries to survive a chaotic fast-food shift.

## Play

GitHub Pages:  
https://stephanus-supandi.github.io/mac_donald_thumb/

## Gameplay

Take customer orders, cook burgers/fries/drinks, package the order, serve customers, manage patience and energy, build combos, and survive random restaurant events.

### Controls

- WASD / Arrow Keys / Joystick — Move
- SPACE / E / ACT — Interact
- Q / DROP — Drop carried item or package
- ESC / P — Pause
- F3 — Debug mode

## Features

- Customer order queue and active-order HUD
- Burger, fries and drink stations
- Packaging and serving system
- Customer patience and angry walkouts
- Score and combo system
- Energy and chaos management
- Random restaurant events
- Procedural Web Audio
- Desktop keyboard and mobile touch controls
- Browser local save/statistics
- Single-file HTML5 Canvas game

## Technology

HTML5 + CSS + JavaScript + Canvas 2D + Web Audio API + localStorage.

No backend is required. Visuals and sound effects are generated in the browser.

## Files

- `index.html` — GitHub Pages entry point
- `mac_donald_thumb.html` — standalone source copy

## Run locally

Open `index.html` in a modern browser, or:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000/
